## 🎀 Sobre o projeto

Um bot para Discord com sistema de economia, recompensas, loja e ranking de usuários.

## ♡ Comandos

| Comando | Função |
|---|---|
| `!saldo` | Consultar carteira |
| `!daily` | Receber moedas diárias |
| `!trabalhar` | Trabalhar e ganhar moedas |
| `!loja` | Visualizar produtos |
| `!comprar` | Comprar itens |
| `!rank` | Ver ranking |

## ୨ৎ Instalação

**1. Instale as dependências**

```bash
pip install -r requirements.txt
```

**2. Configure o token**

Coloque seu token do Discord no arquivo `୨ৎ bot.py`.

**3. Execute**

```bash
python "୨ৎ bot.py"
```
